# 🌿 The Proteinest

A high-performance e-commerce web application built for **The Proteinest** — delivering 100% organic plant protein isolates engineered for fast absorption, effortless digestion, and guaranteed zero bloat.

## 🚀 Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **UI & Styling:** [React 19](https://react.dev/), [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons & Fonts:** Custom SVG Vector Suite, Google Fonts (`Anton`)

## 📂 Core Routes

- **`/` (Home Page):** Interactive hero carousel, featured products, video reels, medical endorsements, comparison table & customer reviews.
- **`/shop` (Shop Page):** Alternating 50/50 split layout for signature products with scroll-reveal motion, live pricing & instant cart CTAs.

## ⚡ Quick Start

```bash
# Clone repository
git clone https://github.com/synchronousbuilddigital/Protein.git
cd Protein

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
